# 时空可组合性的编程范式

**[阅读论文（PDF）](paper.pdf)** · **[中文翻译（Markdown）](paper.zh-CN.md)** · 2026 年 8 月 13 日草稿

> 这是一个仍在积极修订中的预印本，内容可能会发生较大变化；引用时请以最新版本为准，并在依赖其中具体结果前再次确认。

现代软件——从插件系统到可自演化的智能体运行框架——越来越需要_动态组合_，但其形式化基础仍不充分。我们识别出该问题的两个正交维度：_时间可组合性_，即在移除组件时能够完全撤销其副作用；以及_空间可组合性_，即能够声明并以响应式方式管理组件间依赖关系的能力。

我们通过将经典的 effect 与 coeffect 概念提升为运行时机制来处理这两个维度。具体而言，我们形式化了_可回退效应_：每一次上下文变换都携带一个由运行时跟踪的逆变换。我们还形式化了_响应式余效应_：上下文的每次变化都会依据组件的 coeffect 规约通知该组件。我们将 effect 上下文与 coeffect 上下文统一为一种单一的_上下文类型_，并将其确立为一种编程范式。

在此基础上，我们进一步将这些机制组合为_组件_这一概念，并给出一个动态组合演算；其元理论把时空可组合性从单个组件推广到由多个交错组件构成的整个系统。我们在 _Cordis_ 中实现了这些思想。_Cordis_ 是一个面向时空可组合性的元框架，提供带有效应跟踪与余效应解析的核心库，以及具备配置协调与热模块替换能力的声明式组件加载器。
